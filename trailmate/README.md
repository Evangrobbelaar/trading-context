# TrailMate

Road trip and overlanding companion app. Built with React Native + Expo.

## Quick Start (Laptop Setup)

```bash
# 1. Clone the repo
git clone https://github.com/evangrobbelaar/trading-context.git
cd trading-context/trailmate

# 2. Run the setup script (creates ~/Desktop/trailmate)
bash setup.sh

# 3. Open the project in Claude Code
cd ~/Desktop/trailmate
claude   # or open VS Code and use Claude Code extension

# 4. Start the dev server
npx expo start
```

## What setup.sh does

- Creates `~/Desktop/trailmate` as an Expo TypeScript project
- Installs all dependencies (navigation, maps, GPS, sensors, storage)
- Scaffolds the full folder structure with typed stubs
- Copies `CLAUDE.md` so Claude Code has full project context

## Claude Code

Open `CLAUDE.md` first — it contains the full brief, feature priorities, implementation notes, and exactly where to start building.
